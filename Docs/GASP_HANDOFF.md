Facts about this project (checked 2026-10-21)
Player = /Game/ThirdPerson/Blueprints/BP_ThirdPersonCharacter (template Blueprint, CharacterMovementComponent). Game mode BP_ThirdPersonGameMode. C++ gameplay is added at runtime by URPGControllerInputComponent::EnsureHelperComponents() (Source/RPG_CODEX/RPGControllerInputComponent.cpp): combat state, movement abilities (flight), camera mode (first person), interaction, prototype animations, melee hits, strike contact, combat aim, stats, flight animation.
Skeleton: everything of ours is on /Game/Characters/Mannequins/Meshes/SK_Mannequin (UE5 Manny). GASP's animations are on SK_UEFN_Mannequin (2,300+ files under Characters/UEFN_Mannequin). GASP drives Manny via retargeting.
Anim Blueprint: /Game/Characters/Mannequins/Anims/Unarmed/ABP_Unarmed, reparented to C++ URPGAnimInstance (RPGAnimInstance.h). Its proxy runs after the graph and does: spine turn/tilt toward attack aim, the first-person upper-chest swing, and strike-contact IK. Whatever ABP ends up on the player must keep URPGAnimInstance as its parent (or this behaviour must be moved), otherwise aiming, first person and contact break.
Combat/flight clips are RPG_Proto_* and RPG_FP_* in /Game/RPG/Animations/Prototype, generated by Tools/ProtoAnim (poses.py → protoanim.py → ue_import.py; see Docs/ANIMATIONS.md). They play as dynamic montages in DefaultSlot (URPGPrototypeAnimationComponent, URPGFlightAnimationComponent). The new ABP needs a DefaultSlot slot node near the end of its graph (after motion matching, before the output pose).
Flight uses MOVE_Flying; GASP has no flight. While flying, our flight loops own the body (full-body slot).
First person: URPGCameraModeComponent makes a shadow body copying the mesh's anim class (SetAnimInstanceClass(Mesh->GetAnimClass())).
Test dummy (RPGCombatTestDummy.cpp) uses SKM_Manny_Simple + BS_Idle_Walk_Run; leave it alone in stage 1.
Tests: run Automation RunTests RPG headless before/after each stage. Known failures that already exist: DummyWander, the first-person "Shadow setup" one-frame flake.
