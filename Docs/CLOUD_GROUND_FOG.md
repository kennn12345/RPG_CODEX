Native changes: clouds favor stratocumulus, with restrained higher layers/rain-cloud coverage, finer noise breakup, smaller layout scale, slower coherent wind, appropriate albedo/shadow strength and higher sampling. Rain streaks are 14–28 cm rather than 40–70 cm, with thinner distance-aware widths; the wider instant-recycling rain field remains.

URPGGroundFogComponent samples real terrain components, bypassing canopies/roofs and treating water surfaces as the base instead of submerged beds. It lays out 121 world-grid spherical caps (40 m radius, 25 m spacing), using the lowest nearby terrain to avoid projecting cliff-top fog high into neighboring valleys. Each cap ends 609.6 cm above that local base. Most of each sphere is below terrain. Height samples are cached; flying does not raise fog with the camera. Both radial and height extinction must be nonzero because the engine multiplies their coverages. Global weather fog density is removed for fog fronts, retaining clear-weather haze. Config uses analytic isolated local fog, full-resolution composition, zero near start distance and support for 128 volumes. This avoids voxel reprojection bleeding above the shallow cap. Invisible/inactive cells are hidden.

Assets: sun radius 2.4°, moon radius 3° (half previous), star acceptance .4 instead of .8 (half previous), darker background/galaxy haze, shorter/finer/softer rain material. The moon still blocks stars. Applied in the live editor with Tools/World/apply_cloud_groundfog_revision.py; Saved/CloudFogRevision/applied.json and before-state assets are retained.
